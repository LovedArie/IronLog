# Game assets

## Body map (You tab, game on)

`ironlog-bodymap-key.png` — a **colour key**: the front + back muscle
diagram with each skill's area painted one flat colour. The app reads it
pixel by pixel and repaints each area by that skill's level (darker = higher)
and adds stripes when the skill is fading.

| Key colour | Skill |
|---|---|
| Blue `#0000FF` | Arms (biceps, triceps, forearms) |
| Yellow `#FFFF00` | Shoulders |
| Green `#00FF00` | Chest |
| Cyan `#00FFFF` | Back (traps, rhomboids, lats, lower back) |
| Magenta `#FF00FF` | Core (abs, obliques) |
| Red `#FF0000` | Legs (glutes, quads, hamstrings, calves) |
| Grey | Head, neck, hands, feet — not a skill |
| White | Background and the lines between muscles |

Stamina and Mobility have no body area; they show as bars under the map.

Made with ChatGPT on 2026-11-23 from the same grey diagram as the exercise
muscle pictures, then snapped to these 8 exact colours (1200 × 800 PNG).
