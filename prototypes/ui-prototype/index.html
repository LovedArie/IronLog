IronLog — UI prototype

Clickable mock of the phone app (ADR-023). Fake data, nothing saved — reload to start over.

Try this tour

  1. Train now → 30 min → Normal → Home → Start. Log sets with one tap, try ±, wait for the rest timer, do the plank hold. Finish → "How was it?" → Save.
  2. You → ⚙ Settings → turn Play it like a game off. Look at Today and You again.
  3. Train now → Cramming (your 3rd this week) → back on Today, see the pause offer.
  4. Progress → Photos → unlock → Take photos (recovery-code prompt) → Compare.
  5. Log → tap Sunday's strength session → edit or delete a set → Undo.
  6. Settings → Theme Dark, Reduce motion, units kg.

What it tests

  • Every feature has a home (ui-research.md map).
  • One primary button per screen, bottom 40 %.
  • Repeat set = 1 tap; no keyboard to log.
  • Game on/off without losing anything.

Open on a phone: serve this folder (python -m http.server) and visit your PC's IP, or open the published link.
